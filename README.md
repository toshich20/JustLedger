# JustLedger

Backend-приложение для управления личными финансами: учёт доходов и расходов, категории с бюджетами, отчёты, переводы между пользователями и сохранение кошельков в файлы.

## Требования

- Java 17 или новее
- Maven (для сборки и тестов)

## Сборка и запуск

```bash
mvn verify
java -cp target/classes Main
```

Приложение запускается в терминале и работает в цикле до команды `0`. Пользователи хранятся в памяти приложения, поэтому после перезапуска их нужно зарегистрировать заново. Кошелёк каждого пользователя сохраняется в `data/<логин>.txt` при выходе и загружается при следующем входе.

## Команды

В меню команда выбирается номером; `help` или `h` показывает справку в любом меню.

| Команда | Действие |
| --- | --- |
| `1` (гость) | Регистрация |
| `2` (гость) | Вход в аккаунт |
| `1` | Добавить доход |
| `2` | Добавить расход |
| `3` | Создать категорию или задать бюджет существующей |
| `4` | Изменить лимит категории расходов |
| `5` | Удалить категорию |
| `6` | Показать финансовый отчёт |
| `7` | Подсчёт по выбранным категориям (доходы или расходы) |
| `8` | Операции за период |
| `9` | Перевод другому пользователю |
| `10` | Экспорт/импорт отчёта и операций CSV |
| `11` | Выйти из аккаунта с сохранением кошелька |
| `12`, `help`, `h` | Справка с примерами |
| `0` | Выход из программы с сохранением кошелька |

## Пример работы

```text
1 -> anton -> secret
2 -> anton -> secret
1 -> Зарплата -> 20000 ->
1 -> Зарплата -> 40000 ->
1 -> Бонус -> 3000 ->
2 -> Еда -> 300 ->
2 -> Еда -> 500 ->
2 -> Развлечения -> 3000 ->
2 -> Коммунальные услуги -> 3000 ->
2 -> Такси -> 1500 ->
3 -> Еда -> 2 -> 4000
3 -> Развлечения -> 2 -> 3000
3 -> Коммунальные услуги -> 2 -> 2500

```

Пустая строка после суммы пропускает комментарий. Бюджет можно задать и для категории, у которой уже есть операции.

## Экспорт и импорт

- текстовый отчёт сохраняется в файл через пункт `10`;
- операции экспортируются в CSV с колонками `Type;Category;Amount;DateTime;Comment;Budget`;
- колонка `Budget` необязательна, поэтому файлы старого формата без неё тоже импортируются;
- импорт восстанавливает лимиты категорий и добавляет операции в текущий кошелёк.

## Архитектура

- `model` — `User`, `Wallet`, `Category`, `Operation`, `OperationType`;
- `repository` — интерфейсы `UserRepository`, `WalletStorage` и их реализации: пользователи в памяти, кошельки в текстовых файлах;
- `service` — `AuthService`, `FinanceService`, `NotificationService`, `ReportService` и `FinanceCalculator` с общими подсчётами;
- `cli` — `ConsoleCli`: меню, ввод, валидация и табличный вывод;
- `Main` — сборка зависимостей и запуск CLI.

## Тесты

```bash
mvn test
```

Используется JUnit 5. Тесты покрывают авторизацию, операции, бюджеты, оповещения, подсчёты по категориям и периодам, переводы, сохранение/загрузку, CSV, отчёты и CLI. Проверка кода выполняется командой `mvn verify` (Checkstyle и Spotless) и в GitHub Actions.
